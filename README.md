# Drome Apocalypse - version 0.3.2
Total conversion pour Europa Universalis IV (1.37.5.0). Carte : Drome + Ardeche, environ 700 communes jouables. Depart : 1er janvier 2056.

## Installation
1. Fermer EU4.
2. Copier `drome_apocalypse.mod` et le dossier `drome_apocalypse` dans :
   `Documents\Paradox Interactive\Europa Universalis IV\mod`
3. Lancer EU4, activer "Drome Apocalypse" (sans autre mod), jouer en francais.

## Contenu
- Carte de la Drome et de l'Ardeche + 4 iles de la Brume
- La Horde (ZOM) apparait le 1er janvier 2156
- Conseil des Communes Libres (fenetre native : 20 sieges, Commune presidente)
- Milice communale, corps speciaux (mercenaires : gardes-chasse, police municipale)
